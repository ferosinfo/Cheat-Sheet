# TOOL NAME: who.is  
🔗 Tool Link: https://who.is/

## Overview
- Free public WHOIS and domain lookup service  
- Provides registration, DNS, and hosting info for domains

## Key Features

- **WHOIS Lookup**
  - Shows domain registration details (owner, registrar, dates)

- **DNS Records**
  - Displays DNS entries (A, MX, NS, TXT, etc.)

- **IP Lookup**
  - Retrieves IP address info tied to a domain

- **Hosting Info**
  - Shows server and hosting provider details

- **Name Server Info**
  - Lists authoritative DNS servers

- **Domain Age**
  - Displays how long the domain has been registered

## Information/Data Provided
- Domain registrant and contact details
- Registrar name and registration dates
- DNS record set for domains
- IP address and hosting data
- Name server list
- Domain age estimation

## What You Can Do With This Tool
- Quickly get WHOIS data for domains
- Check DNS setup and values
- Find hosting provider and server details
- Determine how old a domain is
- Investigate domain-IP relationships

## Advantages
- Free and easy to use
- Combines WHOIS + DNS + hosting in one lookup
- Useful for quick domain profiling

## Limitations
- Limited historical WHOIS data
- Some fields may be rate‑limited or hidden by privacy
- Not ideal for bulk lookups

## Cybersecurity / OSINT Value
- Good for initial domain reconnaissance
- Useful for basic threat investigation
- Helps identify domain ownership and infrastructure
