# TOOL NAME: DomainHelp
🔗 Tool Link: https://app.domainhelp.com/

## Overview
- Web‑based DNS, WHOIS and domain lookup toolkit by easyDNS
- Helps users query domain/IP info and perform related network checks

## Key Features

- **WHOIS Lookup**
  - Retrieves domain registration details (owner, registrar, dates)

- **DNS Lookup**
  - Queries DNS records for hostnames

- **IPv4 Lookup**
  - Fetches info related to an IPv4 address

- **IPv6 Lookup**
  - Fetches info related to an IPv6 address

- **IDN / Punycode Converter**
  - Converts internationalized domain names to/from Punycode

- **SPF Flattener**
  - Generates a flattened SPF DNS record for email validation

- **What is My IP**
  - Displays the public IP address of the user

## Information/Data Provided
- Domain WHOIS registration data (contacts, dates)
- DNS record information (A, AAAA, MX, TXT, etc.)
- IP address allocation and related network details
- International domain name encodings
- SPF policy output for DNS records

## What You Can Do With This Tool
- Look up WHOIS data for a domain
- Find DNS record values for hostnames
- Check IP block info for IPv4/IPv6
- Convert IDN to Punycode and back
- Flatten SPF records for email setup
- View your own public IP

## Advantages
- Multiple domain/IP tools in one place
- No installation required, browser‑based
- Useful for quick public data checks

## Limitations
- Does not provide deep security reputations or threat scores
- Limited advanced OSINT analytics
- No historical data or change tracking

## Cybersecurity / OSINT Value
- Quick domain and DNS footprinting for investigations
- Useful for initial reconnaissance on domains and IPs
- Helps validate email and DNS configurations
