# TOOL NAME: Robtex
🔗 Tool Link: https://robtex.com/

## Overview
- Web‑based network, DNS, and IP intelligence tool
- Provides multi‑source data for domains, IPs, ASNs, and routing

## Key Features

- **Domain Lookup**
  - DNS records and domain resolution info

- **IP Lookup**
  - Details about IPv4/IPv6 addresses

- **ASN Lookup**
  - Autonomous System Number info and relationships

- **Reverse DNS**
  - Find domains pointing to an IP

- **DNS History**
  - Historical DNS resolutions

- **Network Routing**
  - BGP and prefix route data

- **Blacklist / Reputation**
  - Checks against known public lists

- **Port Scan / Service Info**
  - Visible open ports and protocol services

## Information/Data Provided
- DNS record details (A, MX, NS, TXT, etc.)
- IP owner and network block info
- ASN registration and peer relationships
- Reverse pointers to domains
- Historical DNS results
- Public blacklist/reputation statuses
- Port and service responses

## What You Can Do With This Tool
- Investigate DNS and IP configurations
- Trace routing and network block relationships
- Identify associated domains or hosts
- Check reputation and public block listing
- Examine visible ports/services

## Advantages
- Combines many OSINT sources in one place
- Good for cross‑referencing domain and network info
- Useful for DNS history and network relationships

## Limitations
- Interface can be cluttered or technical
- Some data depends on external sources
- Not focused on deep vulnerability scanning

## Cybersecurity / OSINT Value
- Strong reconnaissance and footprinting support
- Helps map infrastructure and associated assets
- Useful for threat intel and investigation workflows
