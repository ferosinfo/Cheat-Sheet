
# TOOL NAME: ViewDNS.info

🔗 **Tool Link:** [https://viewdns.info/](https://viewdns.info/)

## Overview

- **Comprehensive Toolkit:** A one-stop web portal consolidating over 25 individual DNS, IP, and network diagnostic tools.
    
- **Domain Intelligence:** Specialized in uncovering hidden relationships between domains, IPs, and physical infrastructure.
    

## Key Features

### 1. Reverse Lookup Suite

- **Reverse IP Lookup:** Finds all other websites hosted on a specific server/IP.
    
- **Reverse WHOIS Lookup:** Finds all domains owned by a specific person or company (via name or email).
    
- **Reverse NS Lookup:** Identifies all domains that use a specific nameserver.
    
- **Reverse MX Lookup:** Identifies all domains that share the same mail server.
    

### 2. Domain & DNS Analysis

- **WHOIS Lookup:** Retrieves registration details (registrar, dates, owner info).
    
- **DNS Record Lookup:** Displays all records ($A$, $AAAA$, $MX$, $NS$, $TXT$, $CNAME$, $SOA$).
    
- **DNS Report:** Generates a comprehensive health report of a domain's DNS settings.
    
- **DNSSEC Test:** Checks if a domain has DNS Security Extensions configured.
    
- **Subdomain Discovery:** Uncovers all known subdomains for a specific root domain.
    
- **IP History:** Provides a historical list of IP addresses a domain has pointed to over time.
    

### 3. Network & Connectivity

- **Ping / Global Ping:** Checks latency from multiple geographic locations worldwide.
    
- **Traceroute:** Maps the network hops between ViewDNS servers and the target host.
    
- **Port Scanner:** Scans for common open ports (21, 22, 25, 80, 443, etc.) on a server.
    
- **Is My Site Down:** Verifies if a website is inaccessible globally or just for the user.
    
- **MAC Address Lookup:** Identifies the hardware manufacturer based on a MAC address.
    

### 4. Security & Censorship Tools

- **Spam Database Lookup:** Checks if an IP/domain is listed on 30+ major spam blacklists.
    
- **Chinese Firewall Test:** Checks if a site is blocked by the "Great Firewall of China."
    
- **Iran Firewall Test:** Checks if a site is accessible from within Iran.
    
- **Abuse Lookup:** Finds the designated contact for reporting malicious activity.
    

### 5. Specialized Utilities

- **DNS Propagation Checker:** Checks if DNS changes have updated across global servers.
    
- **Get HTTP Headers:** Displays the raw server headers (Server type, Cookies, Status codes).
    
- **ASN Lookup:** Provides details about an Autonomous System Number (owner, IP range).
    
- **Free Email Test:** Determines if a domain is a free/disposable email provider.
    
- **URL Decode:** Converts encoded URLs into human-readable text.
    

---

## Information/Data Provided

- **Ownership Data:** Names, emails, and organizations linked to domains.
    
- **Infrastructure Mapping:** Shared hosting neighbors, mail servers, and nameserver clusters.
    
- **Historical Data:** Changes in hosting and IP assignments over several years.
    
- **Technical Metadata:** TTL values, server headers, and network path hops.
    
- **Reputation Status:** Inclusion in blacklists or regional censorship blocks.
    

## What You Can Do With This Tool

- **Map Attack Surfaces:** Use Subdomain Discovery and Port Scanning to find entry points.
    
- **Identify Fraud:** Use Reverse IP to find "neighbor" phishing sites on the same server.
    
- **Verify Changes:** Use the Propagation Checker after updating DNS records.
    
- **Investigate Ownership:** Use Reverse WHOIS to link multiple "shell" domains to one actor.
    
- **Global Monitoring:** Check if your site is reachable in restricted regions like China.
    

## Advantages

- **Centralization:** Eliminates the need for multiple command-line tools.
    
- **API Availability:** Offers JSON/XML outputs for developers and automated workflows.
    
- **Ease of Use:** No setup required; results are formatted for quick reading.
    

## Limitations

- **Throttling:** Free web use is subject to rate limiting and captchas.
    
- **API Cost:** Advanced historical data and high-volume queries require a paid subscription.
    
- **Visuals:** Does not provide graphical maps or link-analysis charts (text-heavy).
    

## Cybersecurity / OSINT Value

- **Pivot Pointing:** A single IP can lead to hundreds of related domains for an investigation.
    
- **Infrastructure Attribution:** Helps tie disparate domains to a single hosting entity or individual.
    
- **Reconnaissance:** Foundational for the "Information Gathering" phase of a penetration test.
