# TOOL NAME: ARIN WHOIS
🔗 Tool Link: https://whois.arin.net/

## Overview
- Online WHOIS lookup service from the **American Registry for Internet Numbers**
- Provides registration and allocation details for IP addresses and ASNs

## Key Features

- **IP WHOIS Lookup**
  - Query registration info for IPv4 and IPv6 addresses

- **ASN Lookup**
  - Retrieve details for Autonomous System Numbers

- **NetHandle Info**
  - Lookup network object details in ARIN’s database

- **Organization Search**
  - Find records tied to specific org names or handles

- **Contact and Routing Info**
  - Shows administrative and technical contacts

## Information/Data Provided
- IP block allocation and registry details
- Autonomous System details
- Organization and contact metadata
- Routing and CIDR range info

## What You Can Do With This Tool
- Look up who an IP block is registered to
- Discover ASN ownership and network info
- Find contacts for network abuse or support
- Research network allocations in North America

## Advantages
- Official regional registry data (ARIN)
- Accurate IP and ASN registration records
- Good for network ownership insight

## Limitations
- Only covers ARIN region (North America)
- No DNS or domain WHOIS
- Minimal UI and analytics

## Cybersecurity / OSINT Value
- Useful for identifying IP block owners
- Helps in abuse reporting and network investigations
- Supports attribution of malicious infrastructure
